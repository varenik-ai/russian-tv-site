# tools/ — генераторы страниц сайта

Скрипты, которыми создавались и поддерживаются страницы новых каналов и общие элементы сайта (RU и EN). Все шаги **идемпотентны**: повторный запуск на чистом репозитории ничего не меняет (полный прогон `run_all.sh` на чистой копии воспроизводит текущее состояние сайта; единственное отличие в среде без Pillow — картинки `og:image`, которые ставит `gen_og.py`).

## Требования

- `python3`, `node` (читает список каналов из `CHANNEL_GROUPS` главных страниц);
- `git` и история репозитория (`gen_site.py` берёт нетронутые шаблоны страниц из коммита `827dc43`: `git show 827dc43:kino-detektiv-live/index.html`);
- для `gen_og.py` — Pillow (`pip install pillow`; можно в отдельную папку: `PYTHONPATH=<папка>`) и шрифт Arial Bold macOS (`/System/Library/Fonts/Supplemental/Arial Bold.ttf`).

## Запуск

```bash
tools/run_all.sh            # из корня репозитория: полная пересборка
python3 tools/gen_site.py . # или отдельный шаг (первый аргумент — корень репозитория)
```

После прогона проверьте `git status`, откройте пару страниц локально (`python3 -m http.server`) и запушьте.

## Как добавить канал

1. В `gen_site.py` добавьте кортеж в список `CH`: `id`, slug страницы, категория (`news|ent|kino|kids|music|hobby|sport`), названия RU/EN, описания RU/EN, значок, цвета, ключевые слова RU/EN.
2. Добавьте для него абзац в словарь `MORE` (одна фраза на RU и на EN).
3. Запустите `tools/run_all.sh`. Будут созданы страницы `<slug>/` и `en/<slug>/`, строки в боковых списках всех страниц каналов, записи в главных, карточки на страницах категорий, EN-страница категории, картинка `assets/og/<slug>.jpg`, записи в `sitemap.xml`.
4. Добавьте канал в воркеры и мини-апп (см. `CHANNEL_TEMPLATE.md` в `russia-tv-hub`).

Важно: страницы каналов из списка `CH` **перегенерируются целиком** при каждом запуске — правьте их данные в `gen_site.py`, а не вручную в HTML. Старые каналы (их нет в `CH`) генераторы не трогают, кроме общих блоков (боковые списки, подвал, плеер и т.п.).

## Перенос и удаление каналов

Генераторы только **добавляют**. Чтобы перенести канал в другую категорию или удалить его, сначала отредактируйте списки `REMOVE` / `RELOC_NEW` / `MOVE_OLD` в `gen_moves.py` и запустите `python3 tools/gen_moves.py .` (убирает канал из боковых списков, главных и карточек категорий), затем поменяйте категорию в `gen_site.py` (или удалите кортеж) и запустите `tools/run_all.sh`.

## Что делает каждый скрипт

| Скрипт | Назначение |
|---|---|
| `gen_site.py` | список каналов `CH` + страницы RU/EN, боковые списки, главные, карточки категорий, sitemap |
| `gen_rename.py` | закреплённое переименование «Кино Детектив» → «Viju TV1000 Русское кино» |
| `gen_legal.py` | оговорка для правообладателей в подвале, раздел 4.1 и EN-версия политики конфиденциальности |
| `gen_ads.py` | контакт `dyaltd@gmail.com`, страницы `/advertising/` и `/en/advertising/`, ссылка в подвале |
| `gen_consent.py` | убирает встроенные трекеры (GA4, GTM, Метрика, Clarity), подключает `assets/consent.js` |
| `gen_audit_fixes.py` | исправления по аудиту 18.10.2026 (запускается дважды: после основных шагов и после `gen_channel_texts.py`): убран пустой GTM, самохостинг шрифта Inter, локальные логотипы, JSON-LD без `VideoObject`, title/description (словари `TITLES`, `FORCE_TITLES`, `DESCS`), hreflang блога/спорта, текст пульсирующего баннера (`PULSE`), подключение `assets/cast.js` и строка про Google Cast в политике, правки по Search Console (`FORCE_TITLES`), `noindex` для 8 каналов вне каталога (`NOINDEX_SLUGS`), «Похожие каналы» по кольцу категории, sitemap (`lastmod` из git, без `changefreq`/`priority`, без `noindex`-страниц) |
| `gen_channel_texts.py` | уникальные «О канале» для 24 каналов (словарь `T`: RU+EN, добавляйте сюда новые каналы) и честный FAQ про качество вместо «HD-качестве» на всех страницах |
| `gen_ga_all.py` | подключает `assets/consent.js` на все индексируемые страницы, где его ещё нет |
| `gen_encat.py` | EN-страницы категорий (`/en/news/` …), hreflang на русских категориях |
| `gen_seo.py` | `og:image`, число каналов, sitemap с hreflang, ссылки на главной, `ItemList`, `404.html`, подсказки `preconnect` |
| `gen_ux.py` | хлебные крошки с категорией, размеры логотипов, лента каналов для телефонов (`site-ux.js`) |
| `gen_og.py` | персональные картинки 1200×630 для каналов (`assets/og/`) |
| `gen_blog.py` | статьи блога RU/EN и индексы блога |
| `gen_quality.py` | подключает `assets/quality.js` (выбор качества, в том числе нативный HLS) |
| `gen_playerui.py` | подключает единую панель плеера `assets/player-ui.js` |
| `gen_homeplayer.py` | выбор качества и настройки hls.js на главных страницах |
| `gen_counts.py` | числа каналов на страницах категорий (по количеству карточек) |
| `gen_moves.py` | **разовый** помощник для переноса/удаления каналов (в `run_all.sh` не входит) |

## Ограничения

- Версии скриптов в адресах (сейчас `quality.js?v=8`, `player-ui.js?v=6`, `cast.js?v=3`, `site-ux.js?v=2`, `consent.js?v=3`) заданы в соответствующих генераторах (`gen_quality.py`, `gen_playerui.py`, `gen_homeplayer.py`, `gen_ga_all.py`, `run_all.sh`); при правке `assets/*.js` поднимайте номер и в них, и в страницах (`sed` по `*.html`).
- Тексты «О канале» у 24 каналов (`gen_channel_texts.py`) написаны по общеизвестным признакам и описанию из каталога; их стоит дополнять реальными данными о каналах. У остальных каналов текст берётся из `MORE` в `gen_site.py`.
- Страницы каналов вне каталога (`NOINDEX_SLUGS`) закрыты `noindex,follow`; чтобы вернуть канал в поиск, уберите его из списка и добавьте в каталог главной.
- Тесты после пересборки: `python3 -m http.server` в корне и проверка по sitemap (200, title/description без дублей, hreflang взаимные, у каждого канала по 4 «Похожих»).
- Генераторы рассчитаны на текущую разметку страниц (якоря в HTML и CSS): при серьёзной переверстке шаблонов их придётся обновить.

# russian-tv.com — сайт «Русское ТВ»

Статический сайт на GitHub Pages: `main` → публикация, домен задан файлом `CNAME`. Каждый пуш запускает сборку; изменения доходят до сайта примерно за минуту, кеш может держать старую версию до 10 минут (поэтому у скриптов в `assets/` в адресе есть `?v=N`; при правке скрипта поднимайте номер во всех страницах, где он подключён).

Актуально на **9 октября 2026**. Мини-апп для Telegram и копия кода воркеров лежат в отдельном репозитории `russia-tv-hub` (там же `CHANNEL_TEMPLATE.md` с описанием цепочки источник → воркер → плеер).

## Структура

| Что | Где |
|---|---|
| Главные | `index.html` (RU), `en/index.html` (EN) — список каналов задаётся массивом `CHANNEL_GROUPS` внутри файла |
| Страницы каналов | папки `<slug>-live/index.html` (RU) и `en/<slug>-live/index.html` (EN); в каждой плеер на hls.js, боковой список всех каналов, FAQ, JSON-LD |
| Категории | RU: `novosti/`, `razvlecheniya/`, `kino/`, `detskie/`, `muzyka/`, `hobbi/`, `sport/`; EN: `en/news/`, `en/entertainment/`, `en/movies/`, `en/kids/`, `en/music/`, `en/hobby/`, `en/sport/` |
| Геостраницы | `russkie-kanaly-v-<страна>/`, `russkie-kanaly-za-rubezhom/`, EN: `en/russian-tv-in-<country>/` |
| Блог | `blog/` (RU) и `en/blog/` (EN), статья = папка с `index.html` |
| Служебные | `privacy/` и `en/privacy/` (политика, раздел 4.1 для правообладателей), `advertising/` и `en/advertising/` (для рекламодателей), `about/`, `404.html` |
| Настройки плеера | `proxy.json` — порядок воркеров (`stream.russian-tv.com`, `birch-creek`, `oak-valley`), загружается страницами на лету |
| EPG | `epg.json`, обновляется автоматически (GitHub Actions `update-epg.yml`, скрипт `scripts/update_epg.py`) |
| SEO | `sitemap.xml` (с hreflang RU↔EN), `robots.txt`, `og-image.jpg` и персональные картинки `assets/og/<slug>.jpg` (1200×630) |

Страницы-заглушки с `noindex` (каналы, которых больше нет) остаются как редиректы на главную и в sitemap не входят.

## Скрипты в `assets/`

- `player-ui.js` — единая панель плеера для главных и страниц каналов (звук и громкость, «В ЭФИРЕ» / «К прямому эфиру», качество, кинотеатр, PiP, полный экран; автоскрытие панели; яркая кнопка «Включить звук»; клик = пауза, двойной клик = полный экран; панель ошибки с кнопкой «Повторить» и похожими каналами; подсказка «Видео тормозит?»; клавиши M, F, T, пробел). Старые кнопки полного экрана и звука скрываются, управление идёт через их `.click()`.
- `quality.js` — выбор качества (`rtvQuality.attach(hls, video)` для hls.js, `rtvQuality.attachNative(video, url)` для iPhone/iPad; фиксированный уровень на iPhone включается через воркер `/stream-q`).
- `site-ux.js` — на экранах до 1024 px лента «Другие каналы» под плеером (вкладки категорий + прокрутка).
- `consent.js` — загрузка аналитики: GA4, Google Tag Manager, Яндекс.Метрика (вебвизор отключён), Microsoft Clarity. Баннера согласия нет, всё грузится сразу.
- `ads.js` — реклама Monetag (In-Page Push), стартует через 20 секунд после загрузки; отключается параметром `?noads=1` или константой `ADS_ENABLED`.
- Важно при правках плеера: страницы каналов и главные подключают одни и те же скрипты, но собственный код плеера (`createHls`, `loadStream`, переподключения) у них разный — любые правки логики воспроизведения делайте в обоих местах.

## Как добавить канал

1. Добавьте источник в воркеры и запись в мини-апп (см. `CHANNEL_TEMPLATE.md` в `russia-tv-hub`).
2. Создайте страницы RU и EN, скопировав похожий канал той же категории (например `kinohit-live/index.html` и `en/kinohit-live/index.html`) и заменив: `<title>`, описания, `canonical`, `hreflang`, Open Graph, JSON-LD, заголовок, кнопку/тег категории, абзацы «О канале», FAQ, константу `CH_ID` (должна совпасть с `id` канала в воркере).
3. Добавьте канал в боковой список (`#ch-list`) **на всех страницах каналов** в нужной категории и подсветку `active` на своей странице.
4. Добавьте запись в `CHANNEL_GROUPS` в `index.html` и `en/index.html`, карточку на страницу категории (RU) и перегенерируйте EN-страницу категории, обновите счётчики каналов («58 каналов») и JSON-LD `ItemList` на главной.
5. Добавьте картинку `assets/og/<slug>.jpg` (1200×630) и адреса RU/EN в `sitemap.xml` (с парой `xhtml:link` hreflang).
6. Проверьте страницы локально (`python3 -m http.server`) и на живом сайте.

Для массовых изменений (новые каналы, перенос между категориями, пересборка боковых списков) удобнее скрипт, который правит все страницы одним проходом: в репозитории такого генератора пока нет, страницы последних каналов создавались именно так.

## Известные особенности

- Видео берётся у источников напрямую (воркеры отдают только плейлисты), поэтому скорость и стабильность канала зависят от источника; каналы с `cinerama.uz` дают один уровень качества и могут обрываться примерно через 10–12 минут.
- В `scripts/` лежит `__pycache__` (случайно попал в репозиторий); его можно удалить и добавить в `.gitignore`.
